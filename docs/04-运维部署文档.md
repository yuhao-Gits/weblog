# Weblog 运维部署文档

> ⚠️ **重要提示**：本文档描述的是**传统部署方式**（手动装 MySQL/后端/Nginx），仅作技术参考。
>
> 当前项目推荐使用 **Docker Compose 一键编排部署**（4 个容器：MySQL + Minio + 后端 + 前端）。
> 新手请直接阅读 [**《部署与维护手册（小白版）》**](06-部署与维护手册.md)，那里有完整的手把手教程。
>
> 本文档保留是为了给需要在**非容器环境**下部署的技术人员参考。

## 1. 部署架构

```
用户浏览器
    │ HTTPS（443）
    ▼
Nginx（反向代理 + 静态资源 + Gzip）
    ├── /            → 前端静态资源（dist）
    ├── /api/*       → 后端 8080（去掉 /api 前缀）
    ├── /files/*     → 上传文件静态目录（或 Minio）
    └── /chat/ws     → WebSocket 代理
                              │
                              ▼
                    Spring Boot 应用（:8080）
                              │
                              ▼
                        MySQL 8（:3306）
```

## 2. 环境准备

### 2.1 服务器要求
- Linux（CentOS/Ubuntu）+ Docker
- 已安装 JDK 1.8+（若不用 Docker 运行后端）
- 已安装 Nginx（或 Docker 运行）

### 2.2 安装 Docker
```bash
curl -fsSL https://get.docker.com | sh
systemctl enable --now docker
```

## 3. 数据库部署

### 3.1 Docker 安装 MySQL 8
```bash
docker run -d \
  --name weblog-mysql \
  -p 3306:3306 \
  -e MYSQL_ROOT_PASSWORD=root \
  -e MYSQL_DATABASE=weblog \
  -v /data/mysql:/var/lib/mysql \
  --restart always \
  mysql:8.0
```

### 3.2 初始化表结构
后端首次启动自动执行 `schema.sql` + `data.sql`（生产环境可关闭，见 3.3）。或手动执行：
```bash
mysql -uroot -proot weblog < weblog-server/src/main/resources/schema.sql
mysql -uroot -proot weblog < weblog-server/src/main/resources/data.sql
```

### 3.3 生产配置
使用 `application-prod.yml`：
```bash
java -jar weblog-server-1.0.0.jar --spring.profiles.active=prod
```
生产配置要点：
- `spring.sql.init.mode: never`（由 DBA/运维手动管理脚本）
- 上传目录切换为 `/data/weblog/uploads`
- MyBatis 关闭 SQL 日志

## 4. 后端部署

### 4.1 Dockerfile 方式（推荐）
```dockerfile
FROM openjdk:8-jre-alpine
WORKDIR /app
COPY target/weblog-server-1.0.0.jar app.jar
EXPOSE 8080
ENTRYPOINT ["java","-jar","app.jar","--spring.profiles.active=prod"]
```

构建并运行：
```bash
docker build -t weblog-server .
docker run -d --name weblog-server \
  -p 8080:8080 \
  -v /data/weblog/uploads:/app/uploads \
  --restart always \
  weblog-server
```

### 4.2 Shell 脚本方式
```bash
nohup java -jar weblog-server-1.0.0.jar \
  --spring.profiles.active=prod \
  --server.port=8080 > logs/app.log 2>&1 &
```

## 5. 前端部署

### 5.1 构建
```bash
cd weblog-web
npm install
npm run build    # 产物在 dist/
```

### 5.2 Nginx 配置
```nginx
server {
    listen 80;
    server_name your-domain.com;

    # 前端静态资源
    root /data/weblog/dist;
    index index.html;

    # 前端路由 history 模式兜底
    location / {
        try_files $uri $uri/ /index.html;
    }

    # 后端 API 反向代理（去掉 /api 前缀）
    location /api/ {
        proxy_pass http://127.0.0.1:8080/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }

    # WebSocket 代理（聊天室）
    location /chat/ws {
        proxy_pass http://127.0.0.1:8080/chat/ws;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
    }

    # 上传文件静态资源
    location /files/ {
        alias /data/weblog/uploads/;
    }

    # Gzip 压缩
    gzip on;
    gzip_types text/plain text/css application/javascript application/json image/svg+xml;
    gzip_min_length 1k;
}
```

### 5.3 SSL（HTTPS）
```bash
# 使用 Certbot 申请证书
certbot --nginx -d your-domain.com
```

## 6. Minio 对象存储（可选）

生产环境可将上传文件切换到 Minio 替代本地目录：
```bash
docker run -d --name minio \
  -p 9000:9000 -p 9001:9001 \
  -e MINIO_ROOT_USER=admin \
  -e MINIO_ROOT_PASSWORD=admin123 \
  -v /data/minio:/data \
  --restart always \
  minio/minio server /data --console-address ":9001"
```

## 7. CI/CD（Jenkins）

### 7.1 后端流水线
1. 拉取代码
2. `mvn clean package -DskipTests`
3. `docker build -t weblog-server .`
4. `docker stop weblog-server && docker rm weblog-server`
5. `docker run -d ...`（滚动更新）

### 7.2 前端流水线
1. 拉取代码
2. `npm install && npm run build`
3. 将 `dist/` 上传到服务器 `/data/weblog/dist/`
4. 重载 Nginx

## 8. 监控与运维

### 8.1 日志
- 后端：`logs/app.log`（可用 `tail -f` 实时查看）
- 日志级别通过 `application.yml` 调整

### 8.2 数据备份
```bash
# MySQL 每日备份
mysqldump -uroot -proot weblog | gzip > /data/backup/weblog_$(date +%F).sql.gz

# 上传文件备份
tar -czf /data/backup/uploads_$(date +%F).tar.gz /data/weblog/uploads
```
建议配合 cron 定时执行，保留最近 7 天备份。

### 8.3 健康检查
- 后端：`curl http://localhost:8080/blog/statistics`
- 前端：`curl http://localhost/`
- Swagger 文档：`http://your-domain/api/swagger-ui.html`

## 9. 安全加固清单

- [ ] 修改默认账号密码（admin/123456）
- [ ] JWT secret 使用强随机值，且不硬编码（环境变量注入）
- [ ] MySQL 端口不对外暴露（仅内网）
- [ ] 开启 HTTPS，配置 HSTS
- [ ] Nginx 配置请求频率限制（防暴力破解）
- [ ] 数据库定期备份并异地存储
- [ ] 定期更新依赖版本，关注安全公告
