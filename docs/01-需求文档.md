# Weblog 需求文档

## 1. 项目概述

Weblog 是一个基于 **Spring Boot + Vue 3** 的前后端分离个人博客系统。系统面向个人博主，提供博客前台展示、管理后台维护、站内检索、互动评论、知识沉淀、在线聊天等完整能力。

### 1.1 项目目标
- 提供一个开箱即用的个人博客系统，支持文章发布、分类标签管理、访问统计
- 提供友好直观的管理后台，降低内容维护成本
- 通过站内搜索、知识库、评论、聊天室等增强内容传播与用户互动
- 采用主流技术栈，代码结构清晰，便于二次开发与学习

### 1.2 用户角色

| 角色 | 说明 | 权限 |
|------|------|------|
| 管理员（admin） | 博客拥有者 | 全部读写操作 |
| 游客（guest） | 演示账号 | 仅查询，写操作返回 403 |

## 2. 功能需求

### 2.1 登录鉴权模块
- 用户名 + 密码登录
- 登录页集成滑块验证码（防机器人）
- Spring Security + JWT 身份认证与接口鉴权
- 角色权限控制：管理员可写，游客只读
- Token 过期自动跳转登录页

### 2.2 管理后台
#### 2.2.1 仪表盘
- 展示文章数、分类数、标签数、总浏览量
- 近半年文章发布热点柱状图
- 近一周 PV/UV 访问量折线图
- 统计卡片数字滚动动画

#### 2.2.2 文章管理
- 文章发布（Markdown 编辑器、分类标签关联）
- 文章分页列表、删除、编辑
- 文章置顶 / 取消置顶
- 文章预览跳转

#### 2.2.3 分类管理
- 分类新增、分页列表、删除
- 删除前校验是否关联文章

#### 2.2.4 标签管理
- 标签新增、分页列表、删除
- 关键词模糊查询下拉列表

#### 2.2.5 博客设置
- 博客名称、作者、简介、头像、Logo 维护
- 社交链接（GitHub/Gitee）、二维码维护
- 敏感词配置、评论审核开关、邮件通知配置
- 文件上传（头像/封面等图片）

#### 2.2.6 评论管理
- 评论分页查询、删除、审核（通过/驳回）

#### 2.2.7 知识库管理
- 知识库目录树维护（增删改、二级目录拖拽排序）
- 知识库文章增删改、置顶、发布状态

### 2.3 博客前台
- **首页**：文章分页列表、博主信息卡片、分类标签卡片
- **文章详情**：Markdown 渲染、代码高亮、图片预览、目录（Toc）、上下篇导航
- **归档页**：按年份归档文章列表
- **分类列表页**：某分类下文章分页
- **标签列表页**：某标签下文章分页
- **404 页面**
- 返回顶部按钮

### 2.4 站内搜索（2.0）
- 基于 Lucene 的中文分词检索
- 关键词高亮显示
- 启动时全量初始化索引，文章增删改异步同步索引

### 2.5 评论模块（2.0）
- 树形评论（支持楼中楼回复）
- 根据 QQ 号自动获取头像
- 敏感词检测（配置在博客设置）
- 评论审核开关（开启后评论需后台审核）
- 邮件通知博主与被回复人

### 2.6 知识库（2.0）
- 前台知识库目录树 + 文章列表
- 知识库文章详情（含上下篇、目录侧栏、移动端适配）

### 2.7 公共聊天室（2.0）
- WebSocket 双向通信
- 携带用户信息（昵称/头像）
- 消息类型（系统通知/用户消息）与持久化
- 广播在线用户列表
- 历史消息游标分页加载
- WebSocket 断线重连

### 2.8 行为式验证码（2.0）
- 滑块验证码生成与校验
- 二次校验（一次性凭证防重放）

### 2.9 主题切换（2.0）
- 白天/黑夜主题一键切换，持久化用户选择

## 3. 非功能需求

| 类别 | 要求 |
|------|------|
| 性能 | 接口响应 < 500ms（常规查询）；支持分页，避免全表扫描 |
| 安全 | 密码 BCrypt 加密；JWT 鉴权；写接口角色校验；敏感词过滤；验证码防重放 |
| 兼容性 | 支持主流现代浏览器；移动端响应式适配 |
| 可用性 | 后端幂等初始化脚本，重启不丢数据；异常统一处理 |
| 可维护性 | 前后端分离，模块化划分，统一响应结构、异常处理 |

## 4. 验收标准

- 管理员可完成文章、分类、标签、评论、知识库的全量增删改查
- 游客登录后写操作被拒绝（403）
- 前台可正常浏览首页、文章详情、归档、分类、标签、知识库
- 站内搜索可检索中文关键词并高亮
- 评论可发布、审核、敏感词拦截
- 聊天室可多人实时通信、加载历史消息
- 登录滑块验证码校验通过后放行，重复使用凭证被拒绝
- 主题切换在明暗模式下均可正常阅读
