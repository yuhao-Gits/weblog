# Weblog 开发文档

## 1. 环境搭建

### 1.1 环境要求
| 软件 | 版本 | 说明 |
|------|------|------|
| JDK | 1.8+ | 后端运行环境 |
| Maven | 3.6+ | 后端构建 |
| Node.js | 16+ | 前端构建 |
| MySQL | 8.x | 主数据库 |

### 1.2 数据库初始化
```sql
CREATE DATABASE IF NOT EXISTS weblog DEFAULT CHARSET utf8mb4;
```
后端启动时自动执行 `schema.sql`（建表）与 `data.sql`（种子数据），并初始化默认账号。

### 1.3 后端启动
```bash
cd weblog-server
mvn clean package -DskipTests
java -jar target/weblog-server-1.0.0.jar --server.port=8080
```
> 注意：若环境变量存在 `SERVER__PORT`，会干扰端口配置，务必显式传 `--server.port`。

### 1.4 前端启动
```bash
cd weblog-web
npm install
npm run dev        # 开发模式 http://localhost:5173
npm run build      # 生产打包到 dist/
```

## 2. 项目结构

### 2.1 后端结构
```

├── config/             # JacksonConfig、MybatisPlusConfig、ThreadPoolConfig 等
├── framework/security/ # JwtAuthenticationFilter、JwtUtil、SecurityConfig 等
```

## 3. 开发规范

### 3.1 后端规范
- 统一响应：`Result<T>` / `PageResult<T>`，成功 code = `10000`
- 异常：业务异常抛 `BizException`，由 `GlobalExceptionHandler` 统一处理
- 鉴权：写接口加 `@PreAuthorize("hasRole('ADMIN')")`
- 主键：雪花 ID（Long），经 Jackson 序列化为 String 返回
- 分页：使用 MyBatis-Plus 分页插件
- 异步：`@Resource(name="asyncTaskExecutor")` 手动提交线程池

### 3.2 前端规范
- API 统一走 `/api` 前缀（vite 代理 rewrite 去除）
- 请求封装在 `src/api/`，通过 `request.js` 拦截器统一处理 token/错误
- 前台公共组件放 `src/components/front/`
- 主题：`useTheme` composable + `html.dark` class
- 博客设置：`useBlogSettings` 单例 composable

## 6. 常见问题

### 6.1 SQL 初始化中文乱码
根因是缺少 SQL 脚本编码配置，`application.yml` 需含：
```yaml
spring:
  sql:
    init:
      encoding: UTF-8
```

### 6.2 雪花 ID 精度丢失
JS Number 安全范围仅 2^53，19 位雪花 ID 会丢失精度，导致"文章不存在"。已在 `JacksonConfig` 全局将 Long 序列化为 String 解决。

### 6.3 登录不跳转 / 仪表盘空白
- `request.js` 需用 `String(res.code)` 做严格比较（后端 code 为字符串）
- dashboard 接口路径需与后端对齐

### 6.4 MySQL 连接失败
JDBC URL 的 `characterEncoding` 必须用 `UTF-8`（而非 `utf8mb4`）。

### 6.5 文件写入损坏
本开发环境偶发文件写入损坏（二进制乱码），重要文件写后需回读/UTF-8 校验。
